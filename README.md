# Cargo Ghast

**English** | [简体中文](README.zh-CN.md)

Happy Ghasts that fly like a real mount and carry a chest like a mule.

Put a harness on a Happy Ghast and ride it. It is about three times faster than vanilla, and it turns much more sharply. Look up and down to climb and dive.

Sneak and use a chest on an adult Happy Ghast to attach 27 extra slots. Sneak with an empty hand to open them. While you are riding, press **E**.

If the ghast dies, the chest and everything inside it drop.

Needs [Fabric Loader](https://fabricmc.net/use/) and [Fabric API](https://modrinth.com/mod/fabric-api). Install on both the server and the client.
